Code for the IEEE ToG paper titled "How Could Fault-Tolerant Quantum Computers Be Used In Procedural Content Generation?". 

Both folders are related to their own section in the paper, with Quantum_Game_of_Life containing an example of the quantum cellular automata from the paper. 

The DQI folder contains a pedagogical implementation of decoded quantum interferometry with an example of the constrained solver with a description of the algorithm. It can be easily used with uv and uv sync.
